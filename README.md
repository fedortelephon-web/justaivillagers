# Just AI Villagers

Villagers that actually talk. Each villager gets a personality, a speech style and a memory of
what you said to them; they react to being hit, to monsters nearby, and they chat with each other
in the evening. All of it is generated by a language model running on **your** machine
(Ollama) or any OpenAI-compatible server.

Client-side only: works on any server, no server-side installation, no gameplay changes.

## Requirements

- Minecraft **1.21.11**, Fabric Loader 0.20.1+
- [Fabric API](https://modrinth.com/mod/fabric-api)
- Java 21+
- A model server: [Ollama](https://ollama.com) with `ollama pull gemma3:4b` (default), or an
  OpenAI-compatible endpoint

## Usage

1. Press **V** while looking at a villager to open the dialog screen. Press **V** while looking at
   nothing to address every villager within 12 blocks (up to 5 at once).
2. Type a message, press **Enter**. The screen closes and the answers arrive in chat.
3. Villagers also speak up on their own: when hit, when monsters come close, and in pairs at dusk.

## Languages

Villagers speak the language the game is set to. Nine languages are supported, listed in rough
order of how many Minecraft players use them: English, Turkish, Spanish, Portuguese, German, Polish,
French, Italian and Russian. Regional variants (`es_mx`, `pt_br`, `pt_pt`, ...) use the same language
as their base, and a language the mod does not speak yet falls back to English rather than to a
random other one.

The list comes from a 2026 survey of public server markets, which put English at 65.2% of players,
Turkish at 9.7%, Spanish 4.6%, Portuguese 3.8%, German 2.4%, Polish 1.3%, French 1.3%, Italian 0.8%
and Russian 0.2%. Server markets are a proxy rather than a census — Russian and Chinese players are
under-counted because many play on their own launchers — but the Turkish figure is not an artefact:
it is backed by 431 tracked servers.

The whole village speaks one language at a time: names, character traits, fallback lines and the
prompts that steer the model are all translated, not just the labels. A new language is one file,
`core/LangDataXx.java`, plus an entry in `core/Lang.java`.

## Configuration

The config file lives at `.minecraft/config/justaivillagers.json` and is created on first launch.
Edit it and rejoin a world to apply — the file is re-read on world join.

| Key | Default | Meaning |
| --- | --- | --- |
| `provider` | `ollama` | `ollama` or `openai` |
| `baseUrl` | `http://127.0.0.1:11434` | Server address |
| `model` | `gemma3:4b` | Model name |
| `apiKey` | `""` | Only for `openai`-style servers |
| `requestTimeoutSeconds` | `30` | Per-request timeout |
| `healthTimeoutSeconds` / `healthRefreshSeconds` | `3` / `20` | Backend probe timeout, and how long a probe result is reused |
| `maxTokens` | `160` | Reply length cap |
| `temperature` / `temperatureGroup` | `0.8` / `0.9` | Randomness; higher values make villagers repeat themselves |
| `keepAlive` | `30m` | How long Ollama keeps the model in memory between requests |
| `maxConcurrentRequests` | `5` | Parallel requests cap |
| `historyTtlSeconds` / `maxHistoryMessages` | `900` / `12` | How long a villager remembers a conversation, and how many turns are replayed |
| `speechPaceMsPerChar` | `90` | Milliseconds of pause per character of a line; `0` turns pacing off |
| `speechPaceMinMs` / `speechPaceMaxMs` | `600` / `12000` | Bounds for the computed pause |
| `hurtCooldownMs` | `4000` | How long a villager stays quiet after reacting to a hit; `0` disables the cooldown. Talking to the villager is never affected |
| `groupDialogueDelayMs` | `3000` | Minimum gap between lines of an evening dialogue |
| `spontaneousChance` | `0.0002` | Chance per villager per second of speaking unprompted |
| `enableSpontaneousTalk` | `true` | Villagers speak unprompted |
| `enableGroupDialogues` | `true` | Two villagers talk at dusk |
| `enableEventReactions` | `true` | Reactions to hits and monsters |
| `enableFallbackLines` | `true` | Canned lines when the backend is down |
| `languageOverride` | `""` | Force a language (`en`, `tr`, `es`, `pt`, `de`, `pl`, `fr`, `it`, `ru`). Empty means follow the game language |
| `debugPrompts` | `false` | Echo your own request to chat and log the full prompt (`/justaivillagers status` shows the current state) |

Lines are paced by `length × speechPaceMsPerChar`, clamped to the min/max above. The model answers
much faster than a person talks, so without pacing a whole evening dialogue lands in chat at once.

Out-of-range values are clamped on load instead of crashing the game.

## Commands

All of them work in single player and on a server, because the mod runs on the client:

| Command | What it does |
| --- | --- |
| `/justaivillagers` or `/justaivillagers help` | List the commands |
| `/justaivillagers status` | Server address, model, whether it is downloaded, and any download in progress |
| `/justaivillagers settings` | Open the settings screen (same as pressing **O**) |
| `/justaivillagers reload` | Re-read `config/justaivillagers.json` without rejoining |

On world join the mod prints the settings key and the command hint once, so the controls are
discoverable without reading this file.

## Build from source

```bat
build.bat
```

The jar appears in `build\libs\`. Requires JDK 21+; Gradle is downloaded by the wrapper.

## Project layout

- `src/main/java/com/justaivillagers/core` — pure Java: config, HTTP backends, prompt building,
  history, fallbacks. No Minecraft imports, so it is unit-testable.
- `src/main/java/com/justaivillagers/fabric` — the thin Fabric layer: tick loop, dialog screen,
  keybind, translating game state into the core's `WorldContext`.
- `src/test/java` — dependency-free test harness plus a fake HTTP server. Run with
  `tools\run-tests.bat` (see below) or any JUnit-less runner.
